# Buildings

# Project Overview

In this project, I used C++ and the Standard Template Library (STL), including the `string`, `vector`, and `map` libraries, to model and manage a collection of campus buildings. I created a `Building` struct to represent the properties of each building and implemented a `Campus` class containing functions to manipulate the building data. These functions update the height of an existing building or add a new building if it does not already exist, print building names based on their purpose and height, remove a building from the collection according to its purpose, and repurpose an existing building by changing its assigned use. The project demonstrates the use of classes, structs, vectors, maps, and user-defined functions to manage and organise data efficiently. A `main` file is also included to demonstrate the execution and testing of all implemented functions.
